Mathematische Berechnung

1. Allgemeine Kreisgleichung:
(x - xm)2 + (y - ym)2 = r2
Durch Ausmultiplizieren entsteht die linearisierte Form:
x2 + y2 + a·x + b·y + c = 0
wobei: a = -2·xm,   b = -2·ym,   c = xm2 + ym2 - r2
2. Ausgleichsrechnung (Least Squares):
Für alle 8 Messpunkte wird der mathematische Abstand minimiert:
a·xi + b·yi + c = -(xi2 + yi2)
3. Bestimmung der Geometriegrößen:
Mittelpunkt: xm = -a / 2,   ym = -b / 2
Radius: r = √(xm2 + ym2 - c)
Durchmesser: D = 2 · r
Umfang: U = π · D
Ergebnis des Ausgleichskreises:
Setze 8 Punkte auf den Rand.
